## 🎉 세트만 골라두면 알아서 다 합니다

공부할 **세트를 체크하고 목표 퍼센트만 정해 두면**, 세트마다
**암기 → 리콜 → 스펠 → 테스트**를 차례로 알아서 돌립니다.
이제 모드마다 버튼을 누를 필요가 없습니다.

**단어 세트와 문장(본문) 세트 모두 됩니다.**

---

### 📥 설치

아래 **`Classcard_Setup.exe`** 를 받아서 실행하세요. (Google Chrome이 깔려 있어야 합니다)

> Windows가 `알 수 없는 게시자` 또는 `Trojan:Win32/Wacatac.B!ml`로 경고할 수 있습니다.
> 서명(유료 인증서)이 없는 개인 프로젝트라서 생기는 **오탐**입니다.
> 해결 방법은 [README의 설치 안내](https://github.com/hwb130104-glitch/classcard-macro#%EF%B8%8F-설치할-때-windows-경고가-뜨면)를 봐주세요.

  비밀번호는 Windows 잠금(DPAPI)으로 **이 컴퓨터에만** 저장되고, 파일을 옮겨도 풀리지 않습니다.
- **진도가 한눈에** — 세트 줄마다 암기·리콜·스펠·테스트 상태를 색으로 보여줍니다.

- **대시보드** — 화면 위쪽에 **요약 카드 4장**, 아래쪽에 **실시간 진행 게이지**가 생겼습니다.

  기준 이상이면 건너뛰고, **미달이면 🟠 주황색으로 표시하고 자동으로 다시 응시**합니다.
  ([사용 안내](#️-옵션-사용-안내) 참고)
- **ANTICHEAT 버튼(랜덤 대기)** — 켜 두면 학습 종류 사이, 세트 사이, 테스트 입력 사이에
  무작위로 잠깐씩 쉬며 진행합니다. 처음부터 켜져 있고 빨간색으로 눌려 있습니다.
- **다크/라이트 모드** — 오른쪽 위 ☾/☀ 버튼으로 바꿉니다.
- **설정 자동 저장** — ANTICHEAT 켬/끔, 화면 모드, 클래스별 커트라인을 기억했다가
  다음에 켤 때 그대로 불러옵니다.
- **문장(본문) 세트 지원** — 영작 연습, 듣고 배열, 어순배열 모두 자동으로 풉니다.
  `/`로 끊어 읽는 세트도 토막 단위로 제대로 처리합니다.
- **돌아가는 중에 세트를 더 체크해도 됩니다.** 하던 세트가 끝나는 대로 이어서 합니다.
- **창을 내려놔도 계속 돕니다.** 크롬을 최소화하거나 다른 창으로 가려도 멈추지 않습니다.
  (창을 닫지만 마세요)

### 📊 대시보드 사용 안내

#### 요약 카드 4장 (화면 위쪽)

왼쪽에서 고른 **클래스 전체**를 기준으로 계산하고, **1초마다 자동으로 갱신**됩니다.
학습이 돌아가는 동안 진도가 오르면 숫자도 같이 바뀝니다.

| 카드 | 보여주는 것 |
| --- | --- |
| **암기 평균 진도** | 클래스 안 모든 세트의 암기 진도(%) 평균 |
| **리콜 평균 진도** | 같은 방식의 리콜 진도 평균 |
| **스펠 평균 진도** | 같은 방식의 스펠 진도 평균 |
| **테스트 통과율** | 테스트를 **본 세트** 중 커트라인 이상인 비율. 아래 줄에 `통과 5/8 · 평균 58점`처럼 통과 수와 평균 점수가 같이 나옵니다 |

- 세트 하나는 **100%까지만** 평균에 넣습니다. 200%까지 돌려도 평균이 100%를 넘지 않습니다.
- 아직 안 한 세트는 0%로 계산하고, 테스트를 안 본 세트는 통과율 계산에서 뺍니다.
- 테스트를 하나도 안 봤으면 `-`로 나옵니다.
- 클래스를 바꾸면 그 클래스 기준으로 다시 계산합니다.

#### 실시간 진행 게이지 (화면 아래쪽, 상태 글자 위)

`자동 시작`을 누르면 지금 하는 일이 한 줄과 **파란 게이지**로 나옵니다.

- 왼쪽: `세트 이름 · 암기/리콜/스펠/테스트`
- 오른쪽: `7/12 (58%)` — 몇 장 중 몇 장
- 아래 파란 바가 그 비율만큼 차오르고, **1초마다 자동 갱신**됩니다.
- 학습 종류 사이에 쉬는 동안(ANTICHEAT 켜짐)에는 `다음 학습 준비 중...`, 멈춰 있을 때는 `대기 중`으로 나옵니다.
- 숫자는 사이트 화면 위쪽의 `n/m` 표시를 그대로 읽습니다. 사이트가 **구간(10장 단위)** 기준으로
  세기 때문에, 구간이 넘어가면 게이지가 처음부터 다시 채워집니다.
- **자동 학습에서만** 나옵니다. `수동 모드`로 돌릴 때는 `대기 중`으로 보입니다.

### ⚙️ 옵션 사용 안내

#### 테스트 커트라인 (화면 아래쪽 `테스트 커트라인` 칸)

1. 왼쪽 `내 클래스`에서 정할 클래스를 고릅니다. 칸에 그 클래스의 현재 커트라인이 나옵니다.
2. 칸의 화살표로 점수를 바꿉니다(5점 단위, 기본 **80점**).
   **지금 보고 있는 클래스에만** 적용되고 다른 클래스는 그대로입니다.
3. 세트 줄 오른쪽에 `커트라인 80점`이 표시됩니다.
   클래스에 따로 정해 둔 점수는 **파란 굵은 글씨**, 기본값은 회색입니다.
4. 80점으로 되돌리면 그 클래스의 개별 설정이 풀립니다.

테스트 점수가 커트라인보다 낮으면 세트 줄에 `테스트 70점 미달`이 🟠 주황색으로 나옵니다.

자동 학습은 이렇게 움직입니다.

- **이미 커트라인 이상**이면 그 세트의 테스트는 다시 안 칩니다.
- **미달이거나 기록이 없으면** 테스트를 칩니다. 그래도 미달이면 **최대 3번까지** 다시 응시합니다.
- 3번을 봐도 미달이면 상태 글자에 알려 주고 다음 세트로 넘어갑니다.
- 선생님이 재응시를 막아 둔 테스트는 다시 못 볼 수 있습니다.

#### ANTICHEAT 버튼 (랜덤 대기)

`자동 시작` 옆의 빨간 버튼입니다. 눌러서 켜고 끕니다. 처음부터 **켜진 상태**입니다.

| 상황 | 켜져 있을 때 |
| --- | --- |
| 암기 → 리콜 → 스펠 → 테스트로 넘어갈 때 | 1~3초 무작위로 쉼 |
| 세트에서 세트로 넘어갈 때 | 1~10초 무작위로 쉼 |
| 테스트에서 보기/낱말 조각을 고를 때 | 한 번 누를 때마다 0.1~0.7초 무작위로 쉼 |

- 끄면 쉬지 않고 최대 속도로 진행합니다.
- 쉬는 중에 `정지`를 누르면 바로 멈춥니다.
- 이 옵션은 **진행 속도만 바꿉니다.** 학습 기록과 결과는 사이트에 그대로 남고,
  어떤 점검도 피해 준다고 보장하지 않습니다.

#### 다크/라이트 모드

오른쪽 위 ☾(라이트일 때) / ☀(다크일 때) 버튼을 누르면 바뀝니다.
바꾼 모드는 저장되어 다음에 켜도 유지됩니다.

#### 설정이 저장되는 곳

`%LOCALAPPDATA%\ClasscardMacro\config.json` 에 저장됩니다.
(ANTICHEAT 켬/끔, 화면 모드, 클래스별 커트라인)

- 저장은 임시 파일에 먼저 쓰고 바꿔치기하는 방식이라, 저장 도중 꺼져도 파일이 깨지지 않습니다.
- 화면과 학습이 동시에 설정을 읽고 써도 꼬이지 않게 잠금(Lock)을 걸어 두었습니다.
- 초기화하고 싶으면 이 파일을 지우면 됩니다.
