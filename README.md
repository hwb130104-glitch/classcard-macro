# 클래스카드 매크로

클래스카드(classcard.net) 단어장의 **암기 / 리콜 / 스펠 / 테스트**를 자동으로 풀어주는 Windows 프로그램입니다.

공부할 **세트를 체크하고 목표 퍼센트만 정해 두면**, 세트마다 암기 → 리콜 → 스펠 → 테스트를
차례로 알아서 돌립니다. 단어 세트와 문장(본문) 세트 모두 됩니다.

---

## 📥 설치하기

1. 이 페이지 오른쪽의 [**Releases**](../../releases)를 누릅니다.
2. 맨 위 버전에서 **`Classcard_Setup.exe`** 를 내려받습니다.
3. 받은 파일을 실행해서 설치합니다. (다음 → 다음 → 설치)
4. 바탕화면에 생긴 **클래스카드 매크로**를 실행합니다.

> **Google Chrome**이 컴퓨터에 설치되어 있어야 합니다. 다른 건 따로 설치할 필요 없습니다.

### ⚠️ 설치할 때 Windows 경고가 뜨면

이 프로그램은 학생 개인 프로젝트라 **디지털 서명(유료 인증서)이 없습니다.** 그래서 Windows가 아래처럼 경고할 수 있습니다. **소스 코드는 이 저장소에 전부 공개되어 있습니다.**

- **`Windows의 PC 보호`** / **`알 수 없는 게시자`** (파란 창)
  → **`추가 정보`** → **`실행`** 을 누르면 설치됩니다. 서명이 없는 새 프로그램이면 늘 뜨는 경고입니다.
- **Microsoft Defender가 `Trojan:Win32/Wacatac.B!ml`로 잡는 경우**
  → 끝의 `!ml`은 AI가 "수상해 보인다"고 **추측**한 판정입니다. 프로그램 본체는 검사에 걸리지 않고 설치 파일만 이렇게 걸리는 **오탐**으로, Microsoft에 신고해 두었습니다. 신고가 처리되면 더 이상 잡히지 않습니다.
  → **이 저장소의 [Releases](../../releases)에서 받은 파일이라면** 격리된 파일을 허용해서 설치할 수 있습니다.
    1. Windows 검색에서 **`Windows 보안`** 실행 → **`바이러스 및 위협 방지`** → **`보호 기록`**
    2. `Classcard_Setup.exe`가 적힌 **`위협 격리됨`** 항목을 누름
    3. 오른쪽 아래 **`작업`** → **`장치에서 허용`** (또는 **`복원`**)
    4. 다운로드 폴더에 돌아온 설치 파일을 다시 실행
  → 다른 곳에서 받은 파일은 허용하지 마세요. 그리고 **Defender 자체를 끄지는 마세요.** 이 파일 하나만 허용하면 됩니다.

## ▶️ 사용법

프로그램을 켜면 바로 **자동 학습 화면**입니다. 세트를 고르고 [자동 시작]만 누르면
**암기 → 리콜 → 스펠 → 테스트**를 세트마다 알아서 돌립니다.

### 1. 로그인

처음 한 번은 **자동 조작용 크롬 창**에서 클래스카드에 직접 로그인합니다.

오른쪽 위 **`자동 로그인`** 에 아이디/비밀번호를 저장해 두면, 로그인이 풀렸을 때
프로그램이 알아서 로그인합니다(약 2초). 비밀번호는 Windows 잠금(DPAPI)으로 암호화해
**이 컴퓨터에만** 저장되고, 파일을 다른 컴퓨터로 옮겨도 풀리지 않습니다.

### 2. 클래스와 세트 고르기

- 왼쪽 **`내 클래스`** 에서 반을 고릅니다.
- 오른쪽에 그 반의 세트가 쭉 뜹니다. 공부할 세트를 **체크**하세요.
  - **▶** 표시 = 선생님이 지정한 지금 진도
  - **[단어]** / **[문장]** = 단어장 종류 (자동으로 구분합니다)
  - 각 줄에 **암기 / 리콜 / 스펠 / 테스트** 상태가 색으로 나옵니다.
    **초록** = 다 함(100% 이상), **주황** = 하다 만 것, **회색** = 아직 안 함
- **`모두 선택`** / **`모두 해제`** 로 한 번에 고를 수도 있습니다.

### 3. 목표 정하기

세트 줄 **오른쪽 끝**의 **`○○%까지`** 칸이 그 세트의 목표입니다. **100부터 100단위**로,
화살표를 눌러 조절합니다(직접 입력은 안 됩니다).

- 위쪽 **`목표 한 번에`** 에 값을 넣고 **`모두 적용`** 을 누르면 전부 같은 목표가 됩니다.
- 100%면 한 바퀴, 200%면 두 바퀴입니다.

### 4. `자동 시작`

아래 **`자동 시작`** 을 누르면 고른 세트를 위에서부터 차례로 돌립니다.

- 각 세트마다 **암기 → 리콜 → 스펠 → 테스트** 순서입니다.
- **이미 통과(PASS)한 테스트는 다시 치지 않습니다.** 떨어진(FAIL) 테스트는 다시 칩니다.
- 이미 목표 %를 넘긴 모드는 건너뜁니다.
- **돌아가는 중에 세트를 더 체크해도 됩니다.** 하던 세트가 끝나는 대로 이어서 합니다.
- 멈추려면 **`정지`**.

> 💡 크롬 창을 최소화하거나 다른 창으로 가려도 계속 돌아갑니다.
> 다만 **크롬 창을 닫지는 마세요.**

### 그 밖의 버튼

| 버튼 | 하는 일 |
|---|---|
| **목록 새로고침** | 클래스·세트 목록과 진도를 다시 읽습니다 |
| **재시작** | 프로그램만 다시 켭니다. 크롬 창과 로그인은 그대로입니다 |
| **수동 모드** | 예전처럼 모드를 하나씩 직접 돌리는 창 (아래 참고) |

## 🔧 수동 모드 (예전 방식)

한 모드만 따로 돌리고 싶을 때 씁니다. 오른쪽 위 **`수동 모드`** 를 누르면 열립니다.

1. 왼쪽 위에서 **`단어`** / **`문장`** 을 고릅니다. (고르기 전에는 다른 버튼이 잠겨 있습니다)
2. 크롬에서 공부할 **세트**를 연 뒤 **`단어 불러오기`** 를 누릅니다.
   → `준비 완료! ○○에서 ○개 불러옴`
3. 크롬에서 학습 화면으로 들어간 뒤, 그 모드의 버튼을 누릅니다.

| 단어장 | 모드별 버튼 |
|---|---|
| **단어** | `암기 시작`(들어간 뒤 옆의 `시작`도 누르기) / `리콜 자동 풀이 시작` / `스펠 자동 풀이 시작` / `테스트 자동 풀이 시작` |
| **문장** | `영작 연습 시작` / `리콜 자동 풀이 시작` / `스펠 자동 풀이 시작` / `테스트 자동 풀이 시작` |

> 화면에 열어둔 세트와 불러온 단어가 다르면 **알아서 화면 쪽 세트로 맞춰서** 다시 읽어옵니다.

- **멈추기**: 맨 아래 **`정지`** 버튼 또는 `Esc` 키
- 단어 학습은 **'단어제시'**, 문장 스펠은 **'어순배열'** 방식에 맞춰져 있습니다.

## ❓ 자주 묻는 질문

- **세트 목록이 안 떠요** → 크롬에서 클래스카드에 로그인했는지 확인하고 **`목록 새로고침`** 을 누르세요.
- **"이 학습에 남은 카드가 없습니다(0/0)"가 떠요** → 이미 100%까지 끝낸 구간에 다시 들어간 경우입니다. 사이트가 문제를 안 내줍니다. 다른 세트를 고르거나 목표를 더 올리세요.
- **진도가 목표보다 더 올라가요** → 한 바퀴를 돌면 100%가 오릅니다. 목표 직전에 걸쳐 있으면 한 바퀴를 더 돌아 목표를 넘길 수 있습니다.
- **테스트를 안 쳐요** → 이미 **통과(PASS)** 한 세트는 건너뜁니다. 줄의 테스트 칸이 초록색이면 통과한 것입니다.
- **정답을 못 고르고 가만히 있어요** (수동 모드) → 크롬에 열어둔 세트가 맞는지 확인하세요.
- **크롬 창을 닫아버렸어요** → `목록 새로고침`이나 모드 버튼을 누르면 새 창이 뜹니다.
- **잘 안 되는 부분이 있어요** → [Issues](../../issues)에 어떤 세트의 어떤 모드에서 어떻게 안 되는지 올려주세요.

## 🛠 개발자용 안내

> 여기부터는 소스코드를 직접 실행하거나 수정하려는 분을 위한 내용입니다. 일반 사용자는 볼 필요 없습니다.

### 구조

- Python(Tkinter) GUI + Selenium(Chrome 자동 조작). 코드는 전부 `main.py` 하나에 있습니다.
- 모든 모드가 Chrome 창 하나를 공유합니다. Chrome은 `--remote-debugging-port=9333`으로 띄우고,
  프로그램을 재시작하면 그 포트로 기존 창에 다시 연결합니다.
- **다른 페이지를 읽을 때 탭을 옮기지 않습니다.** 공부 중인 화면에서 `fetch()` + `DOMParser`로
  같은 사이트의 다른 페이지만 받아옵니다(`fetch_set_detail`, `fetch_class_report`,
  `fetch_set_cards`). 주소로 세트를 못 알아내면 예전 방식(북마크릿 JSON을 클립보드에서 읽기)으로 넘어갑니다.
- 진도와 테스트 결과는 **`/ClassReports/users/{클래스}` 한 장**에서 한꺼번에 읽습니다
  (37세트 0.46초). 읽은 값은 `%LOCALAPPDATA%\ClasscardMacro\rates.json`에 캐시합니다.
- 로그인 정보는 Windows DPAPI로 암호화해 `%LOCALAPPDATA%\ClasscardMacro\login.dat`에 저장합니다.
- 화면(Tk)은 메인 갈래에서만, 셀레니움은 워커 갈래에서만 건드립니다. 그 사이는 평범한
  파이썬 값(`_ui_checked`, `auto_cards_seen`, `auto_site_done` …)으로 주고받습니다.

### 사이트 다루면서 알게 된 것들

- 크롬 창이 가려지거나 최소화되면 `document.hidden`이 되고, 그러면 `checkVisibility()`가
  멀쩡히 그려진 것도 전부 `false`로 답한다(CSS 전환이 `opacity: 0`에서 멈춘다).
  그래서 CDP `Emulation.setFocusEmulationEnabled` + 백그라운드 제한 해제 플래그를 쓴다.
- 모드마다 '끝났다'는 화면이 다르고, **스펠은 완료 화면이 아예 없다.** 그래서 사이트의
  `n/m` 카운터와 '서로 다른 카드를 몇 장 했나'를 같이 본다.
- **한 번 들어가면 구간 하나**를 끝내고 나온다(42카드 = 10장씩 4구간). 세트를 100%까지
  하려면 구간 수만큼 들어갔다 나온다.
- '끊어읽기' 문장 세트는 카드 하나가 ` / `로 토막 나 있고, 사이트가 토막마다 한 문제씩 낸다.
- 스펠은 답을 내면 0.1초 만에 채점되지만, **약 1.5초 동안은 [다음 카드]가 안 나와서**
  그 전에는 넘어갈 수 없다. 사이트가 스스로 넘어가 주지도 않는다.
- 낱말이 한두 개뿐인 문장 카드는 맞히면 `Good Job! + [한번 더] [다음 카드]`가 뜬다.
  **[한번 더]는 누르면 안 된다**(같은 카드를 다시 한다).

### 소스에서 실행

필요한 것: Python 3.x, Google Chrome

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

### 설치 파일 만들기

1. PyInstaller로 실행 파일 빌드:
   ```bash
   pyinstaller --onefile --windowed --name "암기" --collect-all selenium main.py
   ```
   `--collect-all selenium`은 꼭 넣어야 합니다. 빼면 selenium의 지연 임포트 모듈과 `selenium-manager.exe`가 빠져서, 빌드는 되어도 실행 중에 selenium 에러가 납니다.
2. `dist/암기.exe`를 `setup.iss`와 같은 폴더로 복사합니다.
3. [Inno Setup](https://jrsoftware.org/isinfo.php)으로 `setup.iss`를 컴파일하면 `Classcard_Setup.exe`가 만들어집니다.

### 사이트 구조가 바뀌었을 때

`main.py` 안의 CSS 셀렉터를 다시 맞춰야 할 수 있습니다.

| 어디 | 셀렉터 |
|---|---|
| 리콜(단어) | `.normal-body`, `.cc-ellipsis` |
| 스펠(단어) | `.spell-content`, `input[name="input_answer"]` |
| 테스트(단어) | `.cc-table.middle.fill-parent` |
| 문장 낱말 조각 | `.scramble-item`(암기·스펠), `.btn-scramble`(리콜), `[class*="c2NyYW1i"]`(테스트) |
| 세트 목록 | `.set-items[data-idx]`, `.set-name-a`, `.set-icon` |
| 세트 카드 | `.flip-card` 안의 `.ex_front` / `.ex_back` |
| 진도 리포트 | `div.class-report-panel.penel-row{세트}` (오타 `penel`이 맞습니다) |

> 테스트 화면의 조각은 클래스 이름이 난독화돼 있습니다(`c2NyYW1ibGUxNzg4...` = base64 `scramble...`).
> 앞부분 `c2NyYW1i`는 항상 같아서 그걸로 잡습니다.
> 또 테스트 조각은 `isTrusted`가 `true`인 **진짜 클릭만** 받습니다(JS로 만든 클릭은 무시).
